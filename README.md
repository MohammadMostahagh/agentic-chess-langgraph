# Agentic Chess System with LangGraph

An advanced agentic chess system built with LangGraph and LLMs.

## Features

- Chess environment with FEN and UCI notation
- Legal move validation
- Automatic retry and self-correction
- LLM fallback strategy
- Zero-shot reasoning
- Chain-of-Thought (CoT)
- Self-Consistency CoT
- Generate-Critique-Refine workflow
- Adaptive strategy routing
- Multi-run benchmarking
- Stockfish-based evaluation

## Technologies

- Python
- LangChain
- LangGraph
- Gemini
- python-chess
- Pandas
- Gradio

## Academic Context

Developed as part of a university Multi-Agent Systems course.
